01要約

Web アプリケーションの開発に約 5 年携わってきました。アジャイル（XP）開発手法と、要件定義から運用まで一貫して関わってきた点が強みだと考えています。PM や実際のユーザーから現在の機能に対するフィードバックをもらい、開発中の機能はできるだけ早く MVP を作り上げてコアな価値を触ってもらうことで、早く方向転換できるような動き方が得意です。

また、マイクロサービスアーキテクチャを採用している現場で、各 API やマイクロフロントエンドごとに異なる言語・フレームワークを採用しているなかでキャッチアップをしつつ開発してきた経験が長いため、技術のキャッチアップに自信があります。ただ言われた通りに機能を開発するのではなく、本当にユーザーが求めている機能なのか PM などと考えながら開発できるエンジニアでありたいと考えています。
